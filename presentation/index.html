Section 1 · Product Overview

What Is IndusWealth?

A personal finance mobile app built for Canadian users that connects to real bank accounts via Plaid, generates AI-powered insights using Google Gemini, and helps users eliminate debt with proven payoff strategies.

🍁 Canada-First

Built for Canadian banking, PIPEDA compliance, and Canadian financial products (TFSA, RRSP, LOC)

🤖 AI-Powered

Gemini Flash 2.0 generates personalized insights — no PII ever sent to the AI model

🔒 Privacy-First

AES-256-GCM encryption, TOTP 2FA, JWT token rotation with family-based reuse detection

💸 Debt Attack

Snowball & Avalanche calculators with real Plaid liabilities + custom debts in one unified view

Section 2 · Architecture

Key Design Decisions

🔁 Two-Layer Caching

Mobile AsyncStorage + server PostgreSQL. 24-hour sync policy avoids excessive Plaid API calls and keeps costs low.

🛡 No PII to AI

Only aggregated financial summaries sent to Gemini. No account numbers, names, or merchant details ever leave the server.

🔑 Token Family Rotation

Refresh tokens use family-based reuse detection. If a token is reused, the entire family is invalidated immediately.

🔐 Encrypted at Rest

All Plaid access tokens stored with AES-256-GCM encryption. TOTP secrets also encrypted before database storage.

Section 4 · Security

Security Features Implemented

🔐 Auth & Tokens

  • AES-256-GCM for Plaid access tokens
  • Refresh token family rotation + reuse detection
  • Account lockout — 5 fails → 15 min cooldown
  • TOTP 2FA with 8 recovery codes (SHA-256 hashed)

🛡 Transport & Headers

  • Helmet security headers (HSTS, CSP)
  • CORS restriction (configurable origins)
  • Request body limit — 10kb
  • Request ID tracking for all API calls

📋 Input & Rate Limiting

  • express-validator on all routes
  • Rate limiting — general + stricter on auth endpoints
  • Trust proxy configured for Render deployment

🗄 Database Schema

20 tables across 4 domains:

  • Core: users, accounts, transactions, sync_log
  • Debt: custom_debts, debt_apr_overrides
  • AI/Content: insights, dismissals, articles, bookmarks…
  • Security: refresh_tokens, login_attempts, totp_secrets, recovery_codes
