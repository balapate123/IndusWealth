3. Vinay Patel — Fullstack Developer

Responsibilities: Backend infrastructure hardening, critical missing features (email verification, password reset), API improvements, and mobile app integration for new backend features.

Week 1: Email Service & Verification (Feb 24–28)

Roadmap Sections: 4.1, 4.2, 13.2

# Task Priority Details Deliverable
1.1 Set up email service P0 Integrate SendGrid (free tier). Create services/email.js. Configure SENDGRID_API_KEY on Render. Working email service
1.2 Email verification on signup P0 Add email_verified, verification_token, verification_expires to users table. Block Plaid linking until verified. Verified email before bank linking
1.3 Resend verification P0 Create POST /users/resend-verification. Rate limit: 3/hour/email. Resend with rate limit
1.4 Mobile: verification flow P0 Verification pending screen, "check your email" message, resend button, deep link/token entry. Mobile verification UX
1.5 Environment validation P0 Validate all env vars on boot: JWT_SECRET (≥32 chars), DATABASE_URL, PLAID keys, ENCRYPTION_KEY (64 hex), SENDGRID_API_KEY. Fail fast. Server refuses to start with weak config
DB Migration Required: Add email_verified, verification_token, verification_expires columns + create password_resets table with indexes.

Week 2: Password Reset & API Hardening (Mar 3–7)

Roadmap Sections: 4.2, 5.2, 7.3

# Task Priority Details Deliverable
2.1 Password reset (backend) P0 Forgot-password + reset-password endpoints. 1hr token, 3 req/hr limit, revoke all sessions on reset. Full password reset API
2.2 Password reset (mobile) P0 "Forgot Password?" link, ForgotPasswordScreen, ResetPasswordScreen. Mobile forgot password UX
2.3 Health check endpoint P1 GET /health checking DB, Plaid, memory, uptime, version. Health endpoint
2.4 Graceful shutdown P1 SIGTERM/SIGINT handlers. Close HTTP, drain DB pool, log shutdown. Clean shutdown
2.5 Uncaught exception handling P1 uncaughtException + unhandledRejection handlers. Log, close, exit code 1. No silent crashes
2.6 Input validation P1 Extend validators to ALL endpoints — dates, amounts, array sizes, string lengths. All endpoints validated

Week 3: Monitoring & Polish (Mar 10–14)

Roadmap Sections: 11.1, 11.5, 5.3, 6.5

# Task Priority Details Deliverable
3.1 Sentry (backend) P0 Install @sentry/node. Init before routes, error handler after. User context (ID only). Backend error tracking
3.2 Sentry (mobile) P0 Install sentry-expo. Capture JS errors + native crashes. User context on login. Mobile crash reporting
3.3 Audit logging P1 Create audit_log table + service. Log: login, password change, Plaid, 2FA, data export, delete. Security audit trail
3.4 Response compression P2 Install + configure compression middleware. Gzip responses
3.5 Connection pool tuning P1 pg pool: max 20, idle 30s, timeout 5s + error handler. Optimized DB connections
3.6 Database SSL P1 ssl: { rejectUnauthorized: true } for production. Encrypted DB connection
Handoff Notes for Vinay: All backend code in packages/backend/src/. Use routes/twoFactor.js as a well-structured route example. DB migrations go in packages/backend/db/. Test with Plaid sandbox: user_good / pass_good.
